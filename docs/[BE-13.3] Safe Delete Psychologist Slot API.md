# [BE-13.3] Safe Delete Psychologist Slot API

## Summary
The safe delete API endpoint (`DELETE /api/psychologist/slots/{slot}`) for Partner Psychologists has been implemented and verified. This endpoint allows psychologists to soft-delete their own consultation slots provided the slot status is `available`. Slots with booked or tentative statuses are protected against deletion.

## Architectural Components

### 1. Authorization & Ownership Guard
- **`App\Policies\PsychologistSlotPolicy`**: Method `delete(User $user, PsychologistSlot $psychologistSlot)` enforces that:
  1. User is an authorized partner psychologist (`manage($user)`).
  2. The slot belongs directly to the psychologist's profile (`$psychologistSlot->psychologist_id === $user->psychologistProfile->id`).
  Attempting to delete another psychologist's slot returns HTTP 403 Forbidden.

### 2. Action & Exception Handling
- **`App\Actions\Psychologist\DeletePsychologistSlotAction`**: Checks `$slot->status === SlotStatus::AVAILABLE`. If false (e.g. `tentative` or `confirmed`), throws `UnprocessableEntityHttpException` with message *"Hanya slot dengan status tersedia yang dapat dihapus."*.
- **`bootstrap/app.php`**: Exception handler configured to render `UnprocessableEntityHttpException` as a JSON response with status 422.

### 3. Controller
- **`App\Http\Controllers\PsychologistSlotController@destroy`**: Calls `Gate::authorize('delete', $slot)`, delegates deletion to `DeletePsychologistSlotAction`, and returns `$this->success(null, 'Slot berhasil dihapus.')`.

## Endpoint Summary

| Method | Path | Auth Guard | Description | Status Codes |
|--------|------|------------|-------------|--------------|
| `DELETE` | `/api/psychologist/slots/{slot}` | `auth:api` (Psychologist) | Soft delete an available slot | 200 OK, 403 Forbidden, 422 Unprocessable |

## Final Verdict
**APPROVED** — Safe deletion rule and ownership protection fully verified via automated test suite.
