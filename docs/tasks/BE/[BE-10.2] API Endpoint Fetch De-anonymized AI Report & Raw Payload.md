Authorization & Identity Logic: Verify that the psychologist has access to this specific confirmed referral. Bypass the anonymization middleware (due to Digital Consent) and return the actual name, nis, and class.

Data Retrieval: Fetch the pre-generated summary string and the filtered raw payload array from the referral_summaries table.

DoD: The API returns a unified JSON response containing the de-anonymized student identity, the static Gemini text, and the filtered raw payload array, returning a 403 Forbidden if consent is missing.
