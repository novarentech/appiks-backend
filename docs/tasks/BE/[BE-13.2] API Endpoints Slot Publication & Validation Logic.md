User Story: As a Front-End System, I need secure endpoints to fetch my current slots and publish new ones without allowing illogical time inputs.

Specific Description:

Create GET /api/psychologist/slots to list the authenticated user's slots.

Create POST /api/psychologist/slots.

Validation Rules: Ensure slot_date is strictly >= the current date (no past slots). Ensure slot_start_time is before slot_end_time. Prevent overlapping slots for the same psychologist_id on the same date.

DoD: The API successfully lists slots, strictly blocks past-date or overlapping slot creation, and returns a 201 Created upon successful insertion.
