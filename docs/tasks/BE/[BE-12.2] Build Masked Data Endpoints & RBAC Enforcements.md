User Story: As a Developer, I must ensure the Principal's API endpoints strictly filter out sensitive medical and chat data to prevent any accidental exposure.

Specific Description: Create a dedicated API endpoint for the Principal's dashboard (e.g., GET /api/headteacher/dashboard/stats and GET /api/headteacher/incidents). Implement strict RBAC middleware. The query must only select metadata columns (id, created_at, status, assigned_counselor_id). Explicitly exclude or unset columns like confession_text, ai_summary, and clinical_notes at the database query level so they never enter the JSON payload.

DoD: The API endpoints return only aggregate stats and safe metadata, successfully returning a 403 Forbidden or automatically stripping sensitive fields if the headteacher role attempts to access forbidden data objects.
